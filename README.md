# SmartOrgan Web

A simple product website built with [Hugo](https://gohugo.io/).

## Compile & run

```bash
# Compile the site (output in public/)
hugo

# Preview with live reload
hugo server
```

Open `http://localhost:1313` in your browser when running `hugo server`.

## Requirements

- [Hugo](https://gohugo.io/installation/) (extended version, v0.128+)
