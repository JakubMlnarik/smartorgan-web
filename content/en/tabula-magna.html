Tabula Magna — MIDI Stop-Tab Unit for Hauptwerk

New product. Tabula Magna is a standalone, self-labelling stop-tab unit for virtual pipe organs — a table-top organ controller that gives Hauptwerk real physical stop tabs, with labels and colours that follow the loaded organ sample set.

Tabula Magna is a flat box with an adjustable stand that sits next to the manual assembly, or in another suitable place. Several units can be used at once (typically 2 units, left and right). It presents 40 physical stop tabs and 5 display widgets, and connects to your computer with a USB cable. Hauptwerk sees it as a MIDI device — no driver, no configuration program, and no console rebuild.

A colour display sits behind the tab rails. It shows the stop names, colours and states that Hauptwerk sends over MIDI, so the labels are never fixed: load a different sample set and the tabs relabel and recolour themselves automatically.

Tabula Magna is a hardware add-on that gives organ software such as Hauptwerk real, physical stop tabs instead of a touchscreen or a mouse. It is the missing piece between a computer running a virtual pipe organ and the feel of a real organ: it makes stop selection convenient while you work comfortably with the individual organ sample sets. Labels and stop indication are kept perfectly in sync with Hauptwerk.

Why Tabula Magna

How it works with Hauptwerk

Everything is configured once, in Hauptwerk, in four steps:

  1. MIDI ports — enable the Tabula input and output ports.
  2. Stop labels — send the stop names and colours to the unit's LCD32 displays.
  3. Pairing the tabs — use Hauptwerk's auto-detect to bind each tab to its stop.
  4. Outgoing MIDI — set what Hauptwerk sends back to light each tab's indication.

Because Hauptwerk stores all of this per sample set, loading a different organ relabels the tabs and reconfigures the unit automatically. A sample set can even send its own appearance settings — fonts, sizes and colours — so each organ carries its own look.
