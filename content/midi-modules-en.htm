MIDI Modules

We offer MIDI modules for building digital organs and MIDI consoles. Each module features analog MIDI IN, MIDI OUT, class-compliant USB-MIDI, an optional High-Speed Analog MIDI Bus (4× standard speed), and a convenient Wi-Fi configuration interface accessible via any web browser.

You can use each module with standard analog MIDI (5-pin DIN), as a direct USB-MIDI device, or both simultaneously — incoming MIDI messages from all interfaces are automatically merged. Since every module already includes built-in USB-MIDI, no external USB-to-MIDI converters are needed.

Matrix-Scanner64

Scans up to 64 inputs (keys) via a diode matrix (8×8). Fully compatible with FATAR keyboards. Includes 3 analog inputs for potentiometers (foot controller, expression pedal, etc.).

📄 User Manual (PDF)

Input-Module16

Reads up to 16 switches via direct connection (2 headers × 8 inputs) — no diode matrix or encoding required. Generates MIDI NOTE ON/OFF or PROGRAM CHANGE messages. Ideal for pistons, stops, and other auxiliary controls.

📄 User Manual (PDF)

Output-Module16

Receives MIDI NOTE ON/OFF messages and controls up to 16 outputs. Each output is a +5 V and FET-switched ground pair (BSS138 MOSFET). Suitable for LEDs, relays, and other low-voltage DC loads.

📄 User Manual (PDF)

Hall-Scanner64

Reads up to 64 Hall sensors and generates velocity-sensitive MIDI NOTE ON/OFF messages. Designed for Mlnarik Organ keyboards and pedalboards equipped with Hall sensors.

📄 User Manual (PDF)
