MIDI Modules

We offer MIDI modules for building digital organs and MIDI consoles. Each module features 5-pin DIN MIDI, class-compliant USB-MIDI, an optional High-Speed Analog MIDI Bus (4× standard speed), and a convenient Wi-Fi configuration interface accessible via any web browser.

Hall-Scanner64

Reads up to 64 Hall sensors (8× MCP3008 ADC chips) over SPI and generates velocity-sensitive MIDI NOTE ON/OFF messages. Designed for Mlnarik Organ keyboards equipped with Hall sensors.

  • Power: 5 V DC / 0.5 A
  • MIDI IN + MIDI OUT (5-pin DIN) with automatic merging
  • USB-MIDI (class-compliant)
  • Wi-Fi configuration including keyboard calibration

Input-Module16

Reads up to 16 switches via direct connection (2 headers × 8 inputs) — no diode matrix or encoding required. Generates MIDI NOTE ON/OFF or PROGRAM CHANGE messages. Ideal for pistons, stops, and other auxiliary controls.

  • Board dimensions: 141×34 mm
  • Power: 5 V DC / 0.1 A (can be powered directly from USB)
  • Internal pull-up — no external resistors needed
  • Wi-Fi configuration with MIDI channel, note, and message type settings

📄 User Manual (PDF)

Matrix-Scanner64

Scans up to 64 keys via a diode matrix (8×8). Fully compatible with FATAR keyboards. Includes 3 analog inputs for potentiometers (foot controller, expression pedal, etc.).

  • Board dimensions: 141×
34 mm
  • Power: 5 V DC / 0.1 A (can be powered directly from USB)
  • 3 analog inputs for potentiometers (MIDI CC)
  • Wi-Fi configuration including analog input settings

    Output-Module16

    Receives MIDI NOTE ON/OFF messages and controls up to 16 outputs. Each output is a +5 V and FET-switched ground pair (BSS138 MOSFET). Suitable for LEDs, relays, solenoids, and other low-voltage DC loads.

    • Board dimensions: 175×34 mm
    • Power: 5 V DC (board consumption ~0.1 A; total depends on load)
    • Max. 0.22 A per output (0.1 A recommended for long-term operation)
    • Wi-Fi configuration with MIDI channel and base note settings
