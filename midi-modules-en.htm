MIDI Modules

We offer general-purpose MIDI modules suitable for a wide range of projects — digital organs, MIDI consoles, custom controllers, and more. Each module features analog MIDI IN, MIDI OUT, class-compliant USB-MIDI, an optional High-Speed Analog MIDI Bus (4× standard speed), and a convenient Wi-Fi configuration interface accessible via any web browser.

You can use each module with standard analog MIDI (5-pin DIN), as a direct USB-MIDI device, or both simultaneously — incoming MIDI messages from all interfaces are automatically merged. Since every module already includes built-in USB-MIDI, no external USB-to-MIDI converters are needed.

MIDI modules have a very simple setup. They are suitable for small as well as complex projects. Chaining decentralized modules ensures a clean and easy installation with minimal wiring, and thanks to the fast analog bus, even many chained modules do not introduce significant latency.

Matrix-Scanner64

Scans up to 64 inputs (keys) via a diode matrix (8×8). Fully compatible with FATAR keyboards. Includes 3 analog inputs for potentiometers (foot controller, expression pedal, etc.).

Price: 70 EUR (excl. VAT)

Input-Module16

Reads up to 16 switches via direct connection (2 headers × 8 inputs) — no diode matrix or encoding required. Generates MIDI NOTE ON/OFF or PROGRAM CHANGE messages. Ideal for pistons, stops, and other auxiliary controls.

Price: 70 EUR (excl. VAT)

📄 User Manual (PDF)

Output-Module16

Receives MIDI NOTE ON/OFF messages and controls up to 16 outputs. Each output is a +5 V and FET-switched ground pair (BSS138 MOSFET). Suitable for LEDs, relays, and other low-voltage DC loads.

Price: 95 EUR (excl. VAT)

📄 User Manual (PDF)

Hall-Scanner64

Reads up to 64 Hall sensors and generates velocity-sensitive MIDI NOTE ON/OFF messages. Ideal for keyboards and pedalboards equipped with Hall sensors, such as those from Mlnarik Organ.

Price: 70 EUR (excl. VAT)

📄 User Manual (PDF)
